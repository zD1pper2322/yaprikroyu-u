# 3D-картинки «Хуторка»

Модели построек, животных, грядок и декора собраны из простых 3D-фигур (three.js r160)
и отрендерены в `farm/sprites/*.webp` с мягким светом и тенью.

- `models.js` — грядки и урожай, амбар, дом, силос, деревья, животные, грузовик, доска;
- `factories.js` — все заводы; `extras.js` — люди, собака, лодка, сундук, декор, забор;
- `render.js` — камера в изометрии игры, рендер, обрезка и якорь;
- `run.js` — запуск через Playwright: `node run.js <папка> [имена]`.

Для запуска положите three.js r160 в `../tjs` (build/three.module.js и
examples/jsm/geometries/RoundedBoxGeometry.js) и поднимите http-сервер в папке выше `tool`.
